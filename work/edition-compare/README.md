**方法**：兩邊各去標點、空白與標記，只留漢字，機械對齊；Wikisource 的 `{{SK notes}}`、`{{SK anchor}}` 內文保留，`{{SKchar}}` 與 Kanripo `&KRnnnn;` 視為一個未解字。全書合併後出現 ≥5 次的單字對（如 黃/黄、脈/脉、上/右）視為字形／寫法異體先行剔除，其餘「殘差」由模型逐條分類為 字形異體／內容差異（高中低）／版式或對齊，見 `edition_diffs_all.json`。**分類為模型判斷，未經人工複核，更未核影像；不判定哪一讀為是。** 重現機械部分：`python3 work/compare_wikisource_skqs.py`。

## 主要發現

1. **《保嬰粹要》**：Kanripo 四庫轉錄與 Wikisource 四庫轉錄逐字幾乎一致（99.8%），32 處差異均為未解字符號（Wikisource 在 弦、瘍、候、棗 等處用 `{{SKchar}}`）或題記，無內容分歧。但兩者同源可能性大，此結果不等於影像核校。
2. **工作稿並非純承應本，含承應影像所無的內容**（2026-09-30 影像核查後更正）：工作稿較四庫本多出的幾處大段，經核承應本影像：《正體類要》陸師道序（`XJ-ZTLY-PRE-P001`）承應本**沒有**（影像自目錄後直接入正文）；《女科撮要》卷首序文（`XJ-NKCZ-PRE-P001`）承應本**沒有**；卷下 P001 的子氣／子懸／子淋段（約409字）承應本**有**、四庫本無（真實的承應／四庫版本差異）；卷下 P028、P030（胎衣不出補治、三案並「觀諸治驗」）承應本**沒有**。即工作稿（jicheng）至少在這些處併入了承應影像以外的內容（該站對《女科撮要》標示嘉靖1546本與承應1654本雙底本），不可一概稱其「依承應本」。此前本節寫作「承應本多出序文」有誤，特此更正。
3. **劑量差異**：多處藥味劑量或單位在兩版不同（如 木香各二分／五分，山藥各一錢／一兩），已寫入相應來源記錄的 `skqs_variant_note`（僅高重要差異，最多列6條）。
4. **與影像核對互證**：九條待核記錄中，《內科摘要》P083 府庠、P178 蒼朮一錢與七片、P179 七片、P308 各一兩，四庫本與承應本圖讀一致，工作稿（公開轉錄）為誤讀；P071、P174 無差異；《癘瘍機要》P018 荊芥二錢五分（承應）／五錢五分（四庫）為真實版本差異，滑石兩版皆三兩（先前圖讀二兩作廢）；《外科樞要》P168 小注四庫本亦含「六味」，現行 preferred_reading 被否定。
5. Wikisource 自身有錯字（如 六昧、酒抺搯辟 疑亂碼），不可當作標準；差異須以影像定奪。

文件：`edition_diffs_all.json`（3159 條分類差異）、`glyph_variant_pairs_ge5.json`（178 個高頻字形對）、`raw_alignment_summary.json`。Wikisource 卷次快照見 `work/source-snapshots/wikisource-skqs/`（含 MANIFEST.json 校驗值）。
