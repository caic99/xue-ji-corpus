## 2. 分层设计与复现规则

- 目标：八书各 **20 案**，合计 **160**。各书 5 条锚点与分布点、5 条含脈／脉字样候选、5 条含诊疗序列相关文字候选、5 条从剩余样本中固定散列选取；组间不放回。
- 特定锚点来自前一轮已定位的案例观察，每组不足 5 时以全书排序的确定位置补齐。《内科摘要》锚点组特意包含待核原案。
- 散列 seed `xueji-retrieval-v1-20261026`，哈希采用 **FNV-1a 32-bit (UTF-8)**。该算法用于**确定性抽样排序**，不是抗篡改加密。数据版本完整性由冻结的 Git commit / Git blob 限定。
- Python 标准库脚本按 `case_id` 排序与固定 FNV 算法复现，默认只读比较；仅显式加 `--write` 重建自动生成结果。**`--write` 会重写 160 案自动候选 JSONL，但不会覆盖独立模型精读文件；在审核前不要用它取代人工结果。**
- 抽取框架不根据旧 `symptoms_quote` 是否为空筛选，故保留《疠疡机要》《保婴粹要》的抽样代表性。选样不是患病人群随机抽样，不能用来估算人群流行率，也不能直接估计整库症状流行率。

## 4. 精读发现的典型误差风险

1. **“善怒”不是“因怒发病”。** 《女科撮要》`XJ-NKCZ-C-V1-P026-1`、以及《疠疡机要》`XJ-LYJY-C-V2-P002`中，“善怒”属于情志特征或素质描述；不宜无标注地升格为此次发病的明确诱因。
2. **“素善饮”不是已确认的致病事件。** 《疠疡机要》`XJ-LYJY-C-V1-P075`可录入饮酒习惯，但未必提供饮酒直接导致皮损的事件链。
3. **同样症状在治疗前后属于不同事实。** 《立斋外科发挥》`XJ-LZWKFH-C-V2-P015-1`的“热益甚”发生于薛己针刺后；《外科枢要》`XJ-WKSY-C-V2-P122-1`中“舌痛口干、脉浮而数”出现于前药之后，不应一律合并为初见症状。
4. **先后用药需识别治疗责任人。** 《口齿类要》`XJ-KCLY-C-H3-P014-1`的“先用补中益气汤”是案中医者开始处方，并不是患者见薛己之前的他医误治。
5. **原案跨物理行。** 《保婴粹要》`XJ-BYCY-C-V5-L0046`的“晡热盗汗”跨两条行式记录，不能通过在一个来源行中截断“盗汗”制造虚假原句；将来应以多个 `evidence spans` 拼接呈现。
6. **病机不可倒填症状。** 如《正体类要》“肝火炽盛，脾土受制”是作者的解释。即便对应案内症状，也不得据此构造患者未报告的症状。
